# Disk Warden — IDE 数据目录清单

> 整理时间：2026-10-16
> 来源：CleanMyDev 博客、各官方文档、社区论坛实测

## 说明

每个 AI IDE / CLI 有两类数据目录：
- **可迁（exhaust）**：缓存、索引、日志、会话记录——可再生，junction 到其他盘无影响
- **不可动（state）**：登录凭证、配置、记忆——动了要重新登录或丢配置
- **未知**：规则不认识的目录，标黄色让用户自己判断

## 三、规则引擎匹配规则

不用逐个IDE硬编码，按文件夹名模式自动分类：

| 文件夹名匹配 | 自动标记 | 原因 |
|---|---|---|
| `Cache`、`CachedData`、`GPUCache`、`Code Cache` | 🟢 可迁 | Chromium标准缓存 |
