## 0. 结论摘要

1. 5 个 Tab 全部有真实内容结构：IDE 数据、项目目录、C 盘全景、规则学习、操作历史，没有"无列表"占位。
2. 7 个指定状态全部可独立进入：扫描中、空态、迁移预览、迁移进度、迁移失败、回滚确认、进程占用阻断；另补迁移成功与未知目录确认 2 个状态。
3. 风险分级在列表、详情、预览三处一致：绿色可迁、红色不可动、黄色未知；红色项没有复选框、没有迁移入口，预览中按数量显式排除。
4. 所有界面文案集中在 `ui/index.html` 顶部 `I18N` 对象中，中英文各 520 个键，键集完全一致；渲染代码不含中英文句子。
5. 数据字段结构与 `data/ide-catalog.json` 对齐：目录项使用 `path / type / safety / reason / handling`，原型仅额外附加 `size_bytes` 演示体积。
6. 破坏性操作在原型中只做状态演示，不触碰真实文件；所有失败路径都保持"源目录完整"的口径。

## 1. 如何打开与评审

### 1.1 打开方式

直接双击 `ui/index.html`，或拖入浏览器。纯静态单文件，无构建、无依赖、无网络请求。

- 设计基准视口：1440×900；最小宽度 1080px。
- 默认语言：中文；可通过 `?lang=en`、顶部导航语言按钮或设置弹窗切换。
- 默认路由：`#projects`。

### 1.2 评审入口

右下角"原型状态"悬浮按钮打开状态面板，按三组列出全部 16 个路由：

| 分组 | 路由 |
|---|---|
| IDE 数据 | `#ide`、`#projects`、`#disk`、`#rules`、`#history` |
| 关键状态 | `#ide/scanning`、`#ide/empty`、`#ide/migrate-preview`、`#ide/migrate-progress`、`#ide/migrate-failed`、`#ide/migrate-success`、`#ide/process-blocked`、`#ide/rollback-confirm`、`#ide/yellow-confirm` |
| 其他页面 | `#settings`、`#feedback` |

面板中的路由可点击直达，也可直接改地址栏 hash。`Esc` 关闭面板。

### 1.3 演示数据声明

原型中的软件、目录、体积、进程 PID、历史记录均为假数据，仅用于评审信息密度与状态表达。任何"清理 / 迁移 / 回滚 / 导出 / 打开目录"都不会修改真实文件。

## 2. 全局外壳与通用规则

### 2.1 布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶部绿色导航 88px：品牌 · 5 个横向图标 Tab · 右上角反馈/设置/语言/版本│
├──────────────────────────────────────────────────────────────────────┤
│ 固定工具栏：页面标题 + 扫描信息 / 页面说明 + 重新扫描                   │
├──────────────────────────────────────────────────────────────────────┤
│ 内容区（独立滚动）                                                     │
│   主-从分栏：左侧竖向列表 Tab + 右侧详情（IDE / 项目 / 历史）           │
│   全宽面板（C 盘全景 / 规则学习）                                       │
└──────────────────────────────────────────────────────────────────────┘
```

- 顶部导航固定 88px（窄于 1280px 时 80px）；品牌在左，5 个横向图标 Tab 紧随其后，系统入口靠右；整体 `min-width:1080px`。
- 视觉为 360 安全卫士风格：绿色渐变顶栏、彩色圆角图标、白色卡片、浅灰内容底与绿色主按钮；风险语义仍保留绿 / 黄 / 红。
- 默认 Tab 为「项目目录」，位于导航第一格；「IDE 数据」排在第二格。
- IDE 数据、项目目录、操作历史采用主-从分栏（`.split-layout`）：左侧 252px 竖向列表 Tab，右侧详情占满剩余宽度；窄于 1180px 时左列收至 200px，仍保持分栏。
- 详情内部留白：详情 14/16px、行间距 5px、行高 42px、列间距 14px；每行信息（勾选、路径+风险徽标、说明、体积、操作）在同一水平线排布，超长文本省略并保留 `title` 悬浮全文。
- 窄于 1280px 时只收窄导航、内边距、列宽与搜索框，不改变信息顺序、不换行；1080px 下五个 Tab 均无横向溢出。
- 只有扫描中、空态等短页面使用 `860px` 限宽单栏并水平居中。
- 内容区独立滚动，页面本身不滚动；顶部导航与固定工具栏固定。
- 主区不再有全宽指标横栏，页面指标由详情内的信息横条表达。

### 2.2 顶部横向导航

| 元素 | 行为 |
|---|---|
| 品牌 | 左侧盾牌图标 + `Disk Warden` + 一行副标题（`AI IDE 磁盘管家` / `Disk manager for AI IDEs`） |
| 5 个 Tab | 横向排列：项目目录、IDE 数据、C 盘全景、规则学习、操作历史；每个 Tab 为彩色圆角图标 + 白色文字 + 计数，当前项以白色半透明底和底部 2px 白线高亮 |
| 计数徽标 | 显示在图标右上角：项目目录 4、IDE 数据 8、规则学习 3（待确认数）、操作历史 5；C 盘全景不显示计数 |
| 反馈问题 / 设置 | 位于整体右上角的系统区，分别打开 `#feedback` / `#settings` 弹窗，不切换当前 Tab |
| 语言按钮 | 系统区胶囊按钮，中文界面显示 `EN`，英文界面显示 `中文`；点击立即整页重渲染 |
| 版本 | 系统区 `v0.1.0 原型`；窄于 1280px 时隐藏 |

### 2.3 固定工具栏

- 位于顶部导航下方且固定不滚动：左侧为页面标题与一行扫描信息 / 页面说明，右侧为 `重新扫描`。
- IDE 数据：显示"上次扫描 2026-10-19 09:42 · 用时 3.4s"与扫描范围 `%APPDATA% · %USERPROFILE% · %LOCALAPPDATA%`；扫描中改为"正在扫描…"。
- 其他 Tab：显示该页一句话说明。
- `反馈问题` / `设置` / 语言 / 版本固定在顶部导航右上角，不随页面滚动。
- 扫描中与空态没有分栏内容，但工具栏 `重新扫描` 与右上角系统入口保持不变。

### 2.4 内容分栏

- IDE 数据、项目目录、操作历史：左侧 252px 列表栏（栏头为标题 + 计数、搜索框、筛选 chips、风险图例，列表为竖向 Tab）+ 右侧详情面板。
- 列表选中项：浅绿底、左侧 3px 绿条；列表只纵向排列，不横向滚动。
- C 盘全景、规则学习：全宽面板上下排列，不采用主-从分栏。
- 详情行固定五列单行网格，风险用左侧 3px 色条表达；数字使用等宽字体与 `tabular-nums`。

未知 Tab 或无 hash 时回退到 `#projects`。深链进入状态路由时，原型会自动补齐可展示的上下文：

- `#ide/process-blocked`：当前软件没有运行进程时，自动切到 Cursor（有 2 个占用进程）。
- `#ide/rollback-confirm`：当前软件未迁移时，自动切到 VS Code，并选中历史记录 h3。
- `#ide/migrate-*`：当前软件已迁移或正在运行时，自动切到 Trae CN（未迁移、无进程）。

### 2.6 弹窗规则

- 弹窗由路由驱动：`#settings`、`#feedback` 以及 7 个 `#ide/*` 状态共用同一套遮罩与容器。
- 打开弹窗前记录来源 hash；关闭（右上角 ✕、取消/返回、点击遮罩）后回到来源页；没有来源时回 `#projects`。
- `Esc` 优先关闭当前弹窗；没有弹窗时关闭"原型状态"面板。
- 点击弹窗内部不会关闭；`role="dialog"`、`aria-modal="true"`、`aria-label` 已标注。
- 迁移预览与进程阻断使用宽弹窗（720px 级别），其余为标准宽度。

### 2.7 可访问性与动效

- 所有可交互元素可键盘聚焦，`:focus-visible` 显示 2px 蓝色轮廓。
- 风险不只靠颜色表达：同时有文字徽标（可迁 / 不可动 / 未知）和符号（⛨ / ?）。
- 开关使用 `role="switch"` 与 `aria-checked`；红色锁定图标带 `aria-label`。
- 遵循 `prefers-reduced-motion`，关闭过渡动画。

### 2.8 桌面端字号阶梯

桌面客户端不能靠浏览器缩放补救：Electron 窗口在 100% DPI 下，12px 以下的中文已经难以辨认。因此字号全部收进 `ui/index.html` 的 `:root` Token，**基准 14px、硬下限 11px**，正文与主操作不低于 13px。

| Token | 值 | 用途 |
|---|---|---|
| `--fs-micro` | 11px | 计数徽标、圆点内符号、品牌副标、分组小标签、tag |
| `--fs-meta` | 12px | 路径、体积、行说明、提示、表头、图例 |
| `--fs-body` | 13px | 次级正文、banner、输入框、筛选按钮、toast |
| `--fs-strong` | 14px | **正文基准（body）**、行主名称、表格、主按钮、导航 Tab |
| `--fs-sub` | 15px | 面板标题、弹窗标题、汇总数值 |
| `--fs-title` | 16px | 品牌名、空态标题 |
| `--fs-page` | 19px | 页面标题 h1、详情标题 h2、弹窗关闭符号 |
| `--fs-kpi` | 26px | 空态图形符号 |

字号上调后同步放行的几何量（否则会出现换行与裁切）：详情行 `min-height` 42→48px、主-从分栏左列 252→272px（1180px 断点 200→220px）、顶部导航 88→96px、导航格 86×76→96×84px、按钮内边距 6/13→7/14px、输入框 5/8→7/9px、复选框 14→16px、开关 30×17→34×19px、时间线圆点 13→16px、弹窗 540→580px / 690→740px。断点只收窄布局，**不再下调字号**。

验证：`ui/_shots/verify-desktop.mjs` 在 1440×900 与 1080×900 两档跑完 16 个路由，横向溢出 0、文字换行 0、中英键集一致（各 520）、无 JS 报错。

## 3. 五个 Tab 的界面结构

### 3.1 IDE 数据（`#ide`）

**入口**：顶部导航"IDE 数据"。

**左侧竖向软件列表**

- 栏头为网格：栏标题、识别数量、搜索框、4 个筛选按钮，下方为风险图例；列宽不足时纵向堆叠，不横向滚动。
- 搜索框：按软件名或目录路径实时过滤；无结果时显示"没有符合筛选条件的软件。"
- 筛选：全部 / 在 C 盘 / 已迁移 / 运行中。
- 软件列表：每行一个软件——左侧首字母色块与运行中小圆点，中间软件名、绿/红/黄目录数量与类型（IDE / CLI / 插件 / 工具），右侧总体积和位置徽标（在 C 盘 / 已迁移）上下排列；选中行浅绿底、左侧 3px 绿条。
- 列表固定 252px 宽（窄于 1180px 时 200px），纵向排列，不横向滚动。

**右侧详情**

- 头部：软件名、根路径（单行省略，悬浮显示全文）、类型、位置、运行中徽标。
- 已迁移横幅：说明数据已在目标盘、通过 junction 链接回原路径，并显示目标路径。
- 进程横幅：列出占用进程名与 PID，并声明不会强制结束进程。
- 信息横条：一条横向通栏把"迁移目标路径 / 预计释放 / 需要空间 / 目标盘剩余与是否充足 / 可迁项数量与体积"并排展示，用竖线分隔；路径列占更宽比例，其余等分。
- 目录行：固定五列单行网格 `锁/复选框 · 路径（内含风险徽标） · 判定原因 · 体积 · 操作`，左侧 3px 色条表达风险；行高 42px、行间 5px。风险徽标紧贴路径左侧，减少一列占位；文本超长时省略，悬浮显示"路径 · 原因"。
  - 绿色：复选框默认勾选；显示 `可迁` 徽标与 handling 标签。
  - 红色：`⛨` 锁定图标代替复选框；显示 `受保护，无迁移入口`；没有迁移入口。
  - 黄色：复选框禁用；显示 `需确认` 按钮；确认后变为可勾选并显示 `已确认`。
- 底部操作：
  - 未迁移：`迁移到目标盘`（无绿色目录时禁用）、`清理缓存`、`打开目录`、`反馈问题`。
  - 已迁移：`迁回 C 盘`、`打开目录`。
  - 右侧说明：未迁移显示"仅清理 Chromium / 编译缓存，不触碰会话与配置。"；已迁移显示"回滚前请先退出 {app}…"。

**交互结果**

- 点击软件行：切换右侧明细，保留当前筛选与搜索。
- 勾选/取消绿色目录：实时更新预计释放、需要空间、可迁项数量。
- 点击黄色行的 `确认此目录`：打开 `#ide/yellow-confirm`。
- 点击 `迁移到目标盘`：依次检查"是否选了目录 → 是否运行中 → 空间是否足够"，分别进入预览、阻断弹窗或 toast。
- 点击 `清理缓存`：toast 显示释放体积（原型模拟），不改变列表数据。
- 点击 `打开目录`：toast"已在资源管理器中打开（原型模拟）"。

### 3.2 项目目录（`#projects`）

**入口**：默认页；顶部导航"项目目录"。

**左侧竖向项目列表**

- 栏头：栏标题、最近活跃项目数量，下方为"清理后需重新安装依赖"说明。
- 4 个项目：disk-warden、acme-web、data-pipeline、mobile-app。
- 项目列表：每行一个项目，首字母色块（C 盘项目为橙色、D 盘项目为蓝色）、项目名、位置徽标 `C:` / `D:`、完整路径（单行省略）、总体积；选中行浅绿底、左侧 3px 绿条。
- 列表固定 252px 宽（窄于 1180px 时 200px），纵向排列，不横向滚动。

**右侧详情**

- 头部：项目名、路径（单行省略，悬浮显示全文）、关联 IDE、最近活跃时间。
- 信息横条：总体积、源码、`.git`、依赖、构建产物五项横向并排。
- 可安全清理：`node_modules` 与构建产物，横向单行展示原因、体积和 `清理依赖` / `清理构建产物` 按钮。
- 必须保留：源码与 `.git`，使用红色风险行与 `⛨` 锁，没有清理入口。
- 底部：`清理缓存`（一次清空依赖与构建产物）、`打开目录`；说明"清理后需要重新 npm install / build，Disk Warden 不会自动执行。"

**交互结果**

- 单行清理：对应体积归零，toast 显示释放量，项目总量同步更新。
- 一键清理：依赖与构建产物同时归零，toast 汇总释放量。
- 原型只改内存数据，不执行 npm 命令、不删除目录。

### 3.3 C 盘全景（`#disk`）

**入口**：顶部导航"C 盘全景"。

**全宽分类表**

- 8 个类别：AI IDE 与 CLI、命令行工具、Git worktree、开发工具缓存、JetBrains 缓存、系统与浏览器、临时文件、模型与大文件。
- 每行单行排布：色块、类别名、一句说明（超长省略）、体积、处理方式标签（Junction 迁移 / 改环境变量 / 改应用配置 / Docker 设置 / 系统提供方 / 直接清理）、`查看位置`。
- `查看位置` 只弹 toast，不打开资源管理器。

**全宽容量条**

- 标题 `C: · 120 GB`，副标题显示已用百分比。
- 6 段容量条：AI IDE、开发工具、系统、模型、其他、可用；图例横向排列显示每段体积。
- 两条示例风险行（单行网格）：绿色"AI IDE 与 CLI"（Junction 迁移，软件无感知）、黄色"系统与浏览器"（受保护，不在处理范围）。
- 底部：`刷新占用`（toast 模拟）、`IDE 数据`（跳 `#ide`）；说明系统文件、页面文件与受保护目录不在处理范围内，工具不做杀毒或系统优化。

### 3.4 规则学习（`#rules`）

**入口**：顶部导航"规则学习"。

**上部：待确认目录（全宽单行列表）**

### 3.5 操作历史（`#history`）

**入口**：顶部导航"操作历史"；迁移成功后"查看操作历史"；回滚完成后自动进入。

**左侧竖向记录列表**

- 栏头：栏标题、记录数量，下方为 4 个筛选按钮（全部 / 迁移 / 清理 / 回滚）与"原型中的记录为演示数据"说明。
- 记录列表：每行一条记录，对象名 + 类型徽标；时间 · 耗时；结果徽标（成功 / 失败 / 已回滚）+ 释放体积；选中行浅绿底、左侧 3px 绿条。
- 列表固定 252px 宽（窄于 1180px 时 200px），纵向排列，不横向滚动。

**右侧详情**

- 头部：对象名、时间 · 耗时、类型徽标、结果徽标。
- 摘要：释放、耗时、对象。
- 路径卡：源 / 目标；失败记录额外显示错误码 `E_VERIFY_MISMATCH`。
- 结果横幅：成功 / 失败 / 已回滚三种语义，文案来自对应记录。
- 执行步骤时间线：迁移 4 步、清理 1 步、回滚 3 步；失败记录最后一步为红色 ✕。
- 底部：可回滚记录显示 `迁回 C 盘`，否则显示禁用的"该操作不可回滚"；`导出记录` 只 toast 模拟；右侧说明"此操作可回滚"或"原型中的记录为演示数据"。

**交互结果**

- 点击可回滚记录 → 打开 `#ide/rollback-confirm`，关闭后回到 `#history`。

## 5. 风险分级与红色保护

### 5.1 三级定义

| 等级 | 颜色 / 符号 | 语义 | 复选框 | 迁移入口 | 典型内容 |
|---|---|---|---|---|---|
| 绿色 | `#22c55e` · 可迁 | 可再生、可重建 | 默认勾选，可取消 | 有 | 缓存、会话、workspaceStorage、日志 |
| 红色 | `#ef4444` · ⛨ 不可动 | 凭证、配置、记忆，动了会丢 | 没有复选框，只有锁图标 | 没有 | Login Data、Local State、settings.json、auth.json、memory |
| 黄色 | `#f59e0b` · ? 未知 | 规则未覆盖，需用户确认 | 确认前禁用，确认后可勾选 | 确认后才可进入清单 | `.trae-cn`、`.trae`、`.dsh\profiles` |

### 5.2 红色保护的三层实现

1. **数据/模型层**：`isChecked()` 对 `safety === 'red'` 恒返回 `false`，无论状态里是否有勾选记录；`toggleCheck()` 对红色直接 return。
2. **控件层**：红色行不渲染复选框，改渲染 `⛨` 锁定图标；红色目录行没有"确认/迁移"类按钮；详情页对红色数量给出显式横幅。
3. **预览层**：预览清单由 `selectedDirs()` 生成，红色永远不会进入；同时显示"受保护项自动排除 + 数量"，让用户知道被排除了多少。

规则冲突时红色永远优先：同一路径同时命中绿色与红色规则，判定为红色。原型规则表底部与规则学习页横幅都明确此策略。

### 5.3 选择与空间计算

- 只有绿色默认选中；确认后的黄色可手动勾选。
- 预计释放 = 已勾选目录 `size_bytes` 之和。
- 需要空间 = `ceil(已选体积 × 1.05 + 64 MiB)`（5% 复制余量 + 64 MiB 缓冲），与产品规格一致。
- 目标盘可用空间读取 `D:` 的演示值 21.7 GB；不足时详情页标红、预览按钮禁用、点击迁移给 toast。
- 体积换算以 1024 为基数，显示单位 GB，内部按字节计算。

### 5.4 目标路径规则

- 目标根目录默认 `D:\DiskWarden\`，可在设置中修改。
- 目标路径 = 根目录去掉末尾反斜杠 + `\` + 软件名去空格：
  - Cursor → `D:\DiskWarden\Cursor`
  - Trae CN → `D:\DiskWarden\TraeCN`
  - VS Code → `D:\DiskWarden\VSCode`
- 已迁移软件使用其运行态记录的目标路径（Windsurf / Kiro / VS Code）。

## 8. i18n 组织

### 8.1 结构

- 单文件顶部定义 `I18N['zh-CN']` 与 `I18N['en']`，每个键对应一句完整文案。
- 渲染代码只调用 `t(key, vars)`，不拼接句子；动态部分通过 `{name}` 占位符插值。
- 回退顺序：当前语言 → `zh-CN` → 返回键名（便于评审发现漏配）。
- 当前规模：中英文各 **520 个键**，键集完全一致（missingEn = []，extraEn = []）。
- 文案按命名空间组织：`app / nav / page / meta / action / common / legend / stats / ide / reason / preview / progress / failed / success / rollback / blocked / yellow / scan / empty / settings / feedback / projects / disk / rules / history / toast / proto / unit`。

### 8.2 切换与持久化

- 顶部导航语言按钮：中文界面显示 `EN`，英文界面显示 `中文`。
- 设置弹窗语言下拉：即时生效，弹窗不关闭。
- URL 参数 `?lang=en` 优先于本地存储。
- 选择写入 `localStorage['dw-lang']`；刷新后保持。
- 切换时同步更新 `<html lang>`、页面标题、顶部导航、固定工具栏、当前页面与弹窗。

### 8.3 不进入 i18n 的内容

以下属于数据或技术标识，不做翻译：软件名、目录路径、环境变量、进程名、PID、错误码、盘符、体积单位 `GB`、演示时间戳、handling 代码值（如 `junction`）。这些值由扫描引擎或规则数据提供，不属于界面文案。

### 10.2 已知限制

1. **演示数据**：软件、目录、体积、历史、进程均为假数据，不代表真实机器。
2. **无后端/IPC**：不读取文件系统、不执行复制/删除/建链，所有破坏性操作只改内存或弹 toast。
3. **状态不持久化**：除语言外，刷新后选择、规则、设置、历史均复位。
4. **进度不自动推进**：扫描与迁移定格在演示进度，便于评审截图；真实实现需接任务事件。
5. **进度弹窗仍可关闭**：底部取消按钮已禁用，但右上角 ✕ 与遮罩仍能退出演示；真实实现应在任务进行中禁用关闭。
6. **预览 5 分钟有效期未实现**：产品规格要求预览 5 分钟内有效，原型未做倒计时与失效。
7. **异常画面不完整**：权限不足、迁移中断、回滚失败三种异常在原型中没有独立画面；以"失败态 + 源目录完整"作为兜底示意，完整流程由实现按产品规格补齐。
8. **规则匹配为演示**：新增/停用/删除规则不会重新扫描目录，只影响表格与统计。
9. **目标根目录校验**：设置中允许任意文本，未校验盘符存在性、可写性与根目录合法性。
10. **导出/打开目录/提 Issue**：仅 toast 模拟，不产生真实文件或外部跳转。

### 10.3 交接建议

- **扫描**：按第 9 章结构产出 catalog 与运行态；扫描进度接入 S1 的 6 个阶段。
- **迁移**：复用 S3/S4/S5/S8 的字段与文案；落实"校验不通过不动源数据"、预览 5 分钟有效、单写任务、不申请提权。
- **回滚**：复用 S6 的确认信息与安全口径；回滚失败需要新增独立状态与文案。
- **验收**：按第 10.1 节逐项验收；异常场景补权限不足、中断、回滚失败。
- **设计还原**：以本文与 `ui/index.html` 为基线；组件尺寸、颜色、间距以页面内的 CSS Token 为准。
