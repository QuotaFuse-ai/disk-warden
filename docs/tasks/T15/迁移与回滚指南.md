# Disk Warden 迁移与回滚指南（用户版）

适用版本：0.9.0-beta.6（Windows 10/11 x64）

Disk Warden 不会删除你的数据。迁移只是把目录**搬走再留一个链接**，回滚就是把链接拆掉、把数据搬回来。下面按「迁移前 → 迁移 → 回滚 → 手动兜底」说明。

## 1. 迁移前

1. **完全退出对应 IDE**（Cursor / Trae / Claude Code 等），包括后台进程。工具在运行时 Disk Warden 会拒绝迁移，提示「工具仍在运行（running）」——这是保护数据，不是报错。
2. 确认目标盘剩余空间 ≥ 待迁移体积（扫描页会显示）。空间不足会在迁移前被拦下。
3. 第一次使用建议先迁一个**缓存类**目录（如 `Cursor\Cache`），确认 IDE 正常后再迁其他。
4. 迁移过程不要关闭 Disk Warden；中途强杀不会丢数据，下次启动会进入恢复流程，但会多一步。

## 2. 迁移做了什么

以 `C:\Users\你\AppData\Roaming\Cursor\Cache` 为例：

1. 在数据盘建立目标目录（默认 `D:\DiskWarden\data\cursor\Cache`）；
2. 复制全部文件并逐项校验；
3. 把原目录改名为临时墓碑（`.dwtombstone-xxxxxxxx`）；
4. 在原位置创建 junction（目录联接），指向目标目录；
5. 读回校验通过后清理墓碑。

完成后资源管理器里原目录带快捷方式箭头，IDE 读写路径不变。删除 junction 只会删链接，**不会**删目标数据。

## 3. 一键回滚

入口有两个：

- **操作历史**页：找到对应迁移记录，状态为「可回滚」的记录有「立即回滚」按钮；
- 扫描页中已迁移的目录，行内也会给出回滚入口。

回滚流程：删除 junction → 把数据搬回原位置 → 恢复迁移时备份的配置 → 写入回滚记录。回滚同样要求**先退出 IDE**。

> 回滚会把数据重新放回系统盘，之前释放的空间会重新占用，这是预期行为。

## 4. 中断后的恢复

如果迁移中途断电、蓝屏或被强杀，下次启动会弹出一条横幅：

- 点 **恢复**：把中断的迁移收尾（能完成就完成，不能完成就还原），结束后可重新扫描；
- 点 **回滚**：直接撤回到迁移前状态。

两条路径都会把任务收敛到终态，不会反复弹横幅。恢复成功后提示「恢复完成」即表示数据已一致。

## 5. 手动兜底（应用打不开时）

以下操作需要**管理员身份的命令提示符**，操作前先备份目标目录。

### 5.1 查看迁移记录

```
<数据目录>\config\migration-jobs\<任务号>.json
```

`<数据目录>` 默认是 `D:\DiskWarden`；设置页能看到实际路径。任务号可在「操作历史 → 操作详情」里找到。记录里 `state` 表示阶段（`DONE` 已完成、`LINKED` 已建链接、`SOURCE_RENAMED` 已改名、`COPY_VERIFIED` 已复制校验等），`source` / `final` 分别是原路径和目标路径。

### 5.2 只删 junction（保留数据）

```cmd
rmdir "C:\Users\你\AppData\Roaming\Cursor\Cache"
```

**必须是 `rmdir`（不要用 `del` / `rd /s`）**。对 junction 执行 `rmdir` 只移除链接；目标目录与数据保持原样。

### 5.3 把数据搬回原位置

1. 先按 5.2 删除 junction；
2. 把 `<目标目录>` 里的**内容**（不是目录本身）复制回原路径；
3. 校验文件数与大小一致后，再删除目标目录。

原路径本身已被占用时，先把占用它的空目录改名，不要直接覆盖。

### 5.4 遇到墓碑目录

若看到 `.dwtombstone-xxxxxxxx`，说明迁移停在「已改名、未建链接」。它保存的是原始数据：

- 原位置没有 junction 时，把墓碑目录改回原名即可；
- 原位置已有 junction 时，说明链接已生效，墓碑是待清理的旧副本，确认目标目录数据完整后再删除。

拿不准就**不要删**，先导出日志反馈。

## 6. 失败时怎么导出日志

1. 打开 Disk Warden → 设置 → **日志目录**（直接打开 `<数据目录>\logs`）；
2. 收集 `app.log`（必要时连同 `app.log.1`、`app.log.2`）；
3. 再附上 `config\migration-jobs\` 下对应任务号的 json；
4. 一并反馈给支持人员。日志与配置**不含明文 API Key**。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示「工具仍在运行」 | IDE 或其后代进程未退出；任务管理器结束对应进程后重试 |
| 迁移报 `WinError 5` | 权限/完整性级别不足，或安全软件拦截创建 junction；用普通（非沙箱、非低权限）账户重试 |
| 回滚后 IDE 找不到配置 | 回滚会恢复迁移前备份的配置；若仍异常，用 5.1 的记录核对 `source` 路径 |
| 原目录变成普通文件夹但占空间 | 说明已回滚成功，数据在系统盘，属正常 |
| 想换数据盘 | 先回滚全部目录，再在新位置重新迁移 |
