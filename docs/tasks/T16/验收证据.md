## A. 「GitHub Device Flow 全流程可走通，且无 secret 硬编码」

- `test_app_auth_client.py::DeviceCodeTest::test_request_posts_the_public_id_and_reads_scope` — 设备码请求只带 `client_id` + `scope=read:user`。
- `test_app_auth_client.py::PollTest::test_request_carries_the_device_grant` — 轮询体含 `grant_type=urn:ietf:params:oauth:grant-type:device_code`，**无 secret**。
- `test_app_auth_client.py::PollTest::test_pending_and_slow_down_are_passed_through` / `test_terminal_errors_are_passed_through` — `authorization_pending`/`slow_down`/`expired_token`/`access_denied` 原样上交状态机。
- `test_app_auth_device_flow.py::SuccessTest::test_pending_then_token_authenticates` — 拿到 token 后进入 `authenticated`。
- `test_app_auth_service.py::ConfiguredFlowTest::test_full_round_trip_signs_in_and_stars` — 设备码 → 轮询 → 换 token → 读资料 → `signed_in=true`；断言返回体与 `auth.json` 均不含 token，且只访问白名单主机。
- `test_app_auth_config.py::DefaultsTest::test_config_has_no_secret_field_at_all` — 配置对象根本没有 secret 字段。
- `test_app_auth_config.py::DefaultsTest::test_scope_is_read_user_only` — scope 仅 `read:user`（不申请 `repo`/`public_repo`）。
- `test_app_auth_config.py::StarAndRepoTest::test_star_url_uses_the_public_endpoint` — Star 判定走公开接口 `/users/{login}/starred/QuotaFuse-ai/disk-warden`。

## B. 「登录成功进主界面，并弹出半透明 Star 蒙版，可关闭」

- 登录成功：流程进入 `authenticated` → `signed_in=true` → UI 轮询到终态后自动 `welcome.seen` 并关闭欢迎页（`ui/index.html`：`startAuthPolling` / `finishLogin`）。
- 未 Star → `star.pending=true`（`test_full_round_trip_signs_in_and_stars`），`renderStarOverlay` 渲染半透明遮罩 + 白色卡片。
- 可关闭：遮罩点击、关闭按钮、`Esc` 均调用 `App.starDismiss`；`test_star_prompt_can_be_reopened_and_dismissed` 断言 dismiss 后 `pending=false/dismissed=true`，`star.show` 可再次唤起（设置页入口）。

## C. 「跳过登录可用全部本地功能」

- 跳过只写 `welcome_seen=true`（`test_welcome_seen_is_persisted`），不写任何功能开关；本地 RPC 与登录态无耦合，`auth_status` 为纯读。
- 未登录时 `star.give` 返回 `AUTH_REQUIRED`（`test_star_requires_a_login`），不静默失败、不阻塞。

## D. 「失败有可读提示且不阻塞使用」

- 所有错误带稳定 `code` + `message_key=error.<CODE>` + `detail`，UI 侧 `authErrorText()` 映射中英文案，缺翻译时降级 `error.AUTH_FAILED`，不会出现原始堆栈。
- `test_app_auth_device_flow.py::ErrorTest::test_repeated_network_failures_stop_the_flow` — 连续 3 次网络失败终止并带 `attempts`，不会无限重试。
- `test_app_auth_device_flow.py::ErrorTest::test_deadline_expires_the_flow_without_polling` — 到期不再轮询。
- `test_app_auth_service.py::ConfiguredFlowTest::test_cancel_releases_the_flow` — 取消后流程 `cancelled` + `AUTH_CANCELLED`，可重新登录。
- 失败/超时/取消均为终态，欢迎页始终保留「跳过」按钮，任何情况下都能进入主界面。

## H. 真实端点冒烟（只读，一次）

用内置公开 client id 直接请求 `POST https://github.com/login/device/code`（无 secret、无轮询、不落盘）：

```
configured: True  provider: github
user_code=9871-C844  verification_uri=https://github.com/login/device
expires_in=899  interval=5  device_code=<40 字节，已省略>
```

返回结构与 RFC 8628 一致，说明内置 id 的 Device Flow 已在 GitHub 侧启用；轮询、换 token、读资料由注入 opener 的用例覆盖，离线环境下不执行真实授权。
