# T16 实现说明：欢迎页、GitHub Device Flow 登录与 Star 引导

> 范围：本任务全部两段合并交付。Python 3.8 兼容（决策 0005），无新增第三方依赖。
> 本文件取代此前的「第一阶段（回环回调）」版本，旧方案已整体删除。

## 1. 目标与最终做法

| 项 | 最终做法 |
|---|---|
| 欢迎页 | 首次启动全屏卡片：GitHub 登录（可选）+「跳过登录，直接使用全部本地功能」 |
| 登录方式 | **GitHub Device Flow（RFC 8628）**：不监听本地端口、无 `state`、无 PKCE、无 client secret |
| client id | 作为**公开常量**内置，`DISK_WARDEN_GITHUB_CLIENT_ID` 可覆盖（便于测试） |
| scope | 只要 `read:user`；不申请 `repo` / `public_repo` |
| Star 判定 | 公开接口 `GET /users/{login}/starred/QuotaFuse-ai/disk-warden`，204=已 Star / 404=未 Star |
| Star 蒙版 | 登录成功且未 Star 时弹出，半透明、可关闭；设置页「Star 提示」可再次唤起 |
| Gitee | 仅保留「打开仓库页」按钮；仓库未建立期间显示「即将上线」并禁用；不授权、不读 token、不做服务端判定 |
| 跳过登录 | 主路径。跳过只写 `welcome_seen=true`，不改任何本地功能开关 |
| 网络 | 只允许 `github.com` 与 `api.github.com`，由传输层白名单强制 |

## 2. 目录与文件

## 4. 流程状态机

`pending → authenticated`

终态：`authenticated / failed / cancelled / expired`。

- `authorization_pending`：继续按 `interval` 轮询；
- `slow_down`：间隔 +5 秒（上限 60 秒）；
- `expired_token`：`expired`（UI 提示重新登录）；
- `access_denied`：`failed` + `AUTH_CANCELLED`（可重试）；
- 连续 3 次网络错误：`failed`，`detail.attempts` 记录次数；
- 到期（`expires_in`，默认 900 秒）：`expired`，线程退出；
- 用户取消 / 关闭应用：`cancelled`，线程退出。

`device_code` 不出现在 `status()`；UI 只拿到 `user_code`、`verification_uri`、`expires_at`、`interval`。

## 5. UI 行为

- `state.auth` 与迁移流程的 `state.data.flow` 分开，避免与 `modalKind()` 冲突。
- 登录中：醒目展示 `user_code`（等宽大字、可全选），提供「复制代码」「打开授权页面」「取消登录」，并显示剩余有效秒数。
- 成功后：自动 `welcome.seen`，进入主界面；未 Star 则弹 Star 蒙版。
- Star 蒙版：`Star on GitHub`（打开仓库页后回读公开 Star 状态）、`我已 Star，刷新状态`（`star.check`）、Gitee 按钮（仓库未建 → 禁用 +「即将上线」）、关闭。
- 跳过登录：按钮默认聚焦，`welcome_seen=true` 后不再出现（设置页「账号」可重新打开欢迎页）。
- 失败/超时/取消：可读提示 + 重试，不阻塞任何本地功能。
- 宿主未返回 `auth.providers` 时使用内置兜底：GitHub 显示「未配置」，绝不假装可登录。

## 6. 安全取舍

- token 只用 DPAPI（`CryptProtectData`，`UI_FORBIDDEN`）落盘；不可用时仅存内存并在状态里回报
  `secure_storage=false`，**没有明文兜底**；退出登录即删除文件。
- `auth.json` 只存 welcome/star 标志与公开资料（`provider/login/name/avatar_url/starred/时间戳`），含白名单字段清洗与长度截断。
- token 只出现在 `Authorization` 头，且只在进程内；不进日志、不进 `status()`、不进任何错误 detail。
- 主机白名单在传输层强制：任何非 `github.com` / `api.github.com` 的 URL 直接拒绝（`reason=blocked_host`）。
- 响应体读取上限 256 KiB 并显式关闭。

## 7. 关键决策与偏差

1. **由回环回调改为 Device Flow**：桌面端没有可用的固定回调端口，Device Flow 不需要 secret、不需要本地服务，也更符合「不注册账号/不额外配置」的约束。原 `flow.py` 与相关文案整体删除，不留双分支。
2. **Gitee 移除 OAuth**：Gitee 侧需要独立的 OAuth 应用与 secret，本次不投入；改为常量化的仓库链接按钮，仓库建立后只需把 `GITEE_REPO_AVAILABLE` 置真。
3. **T25 keystore 不在当前基线**：`src/core/ai/keystore.py` 只存在于 `origin/integration/t24-t25-t12d`，`main` 上没有。为避免把无关分支的代码拉进来，`store.py::TokenStore` 自建了同等的 DPAPI 封装，并把 `TokenStore` 作为合并时的替换缝（接口一致：`available/save/load/clear`）。
4. **文档漂移（未在本任务修改）**：`docs/功能需求.md` §4.5 与 `docs/specs/架构设计-v1.0.md` §5.2 仍描述「GitHub/Gitee 双平台 + 回环回调」。这两份是**功能需求/架构**的基线文档，不属于 T16 可改范围，已在 issue 评论中列出待同步项。
