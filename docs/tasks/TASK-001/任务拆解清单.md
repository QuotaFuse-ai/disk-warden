## 一、优先级原则

- **P0（必须，2 周内）**：扫描 → 判定 → 迁移 → 验证 → 回滚 这条主链路跑通，能在沙箱里安全完成一次迁移与回滚（先在 Windows 达成）。
- **P1（重要，主链路后）**：Windows + macOS 双平台打包、托盘、欢迎页/OAuth、其余 4 个 Tab。macOS 属第一期交付物（见决策 0004）。
- **P2（可延后）**：云端规则同步、CI、自动更新。
- **不做（本期）**：官网、hub/dsk 三端、账号系统、支付、论坛。
- **降级规则**：任何 P1 与 P0 抢工时，P1 让路；P0 里界面美化让路于数据正确性。
