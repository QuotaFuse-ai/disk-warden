# Disk Warden 隐私说明（0.9.0-beta.6）

## 1. 一句话概括

默认完全离线：扫描、迁移、校验、回滚都在本机完成，不联网、不上传。只有你**手动开启**「AI 辅助分析」并**单独同意**后，程序才会把少量脱敏的目录元数据发给你**自己配置**的模型服务商。

## 2. 默认状态

| 项目 | 默认值 |
|---|---|
| AI 辅助分析 | **关闭** |
| 网络请求（遥测、统计、崩溃上报） | **无** |
| 扫描/迁移/回滚 | 纯本地文件操作 |
| API Key | 未设置 |

关闭 AI 时，程序不会向任何服务器发起请求。

## 3. 开启 AI 需要两步

1. 打开「AI 辅助分析」开关；
2. 阅读并勾选**同意**（`ai_consent`）。

只开开关未同意，或只填 Key 未开开关，都不会联网。任一条件不满足，分析器直接返回「不可用」。

## 4. 开启后发送什么

AI **只处理扫描结果里判定为「未知」（黄色）的目录**，且结果只能作为建议，始终需要你确认；它不能覆盖规则判定的「勿动」，也不会触发自动迁移。

每条请求只包含以下元数据：

| 字段 | 内容 |
|---|---|
| `path` / `path_segments` | 路径的**末尾若干段**（默认 3 段，最多 6 段），已去掉盘符、用户目录与用户名 |
| `depth` | 目录深度 |
| `file_count` | 文件数量 |
| `total_bytes` | 目录总大小 |
| `extensions` | 扩展名分布 |

**不会发送**：文件内容、文件名、完整路径、用户名、计算机名、环境变量、API Key、迁移记录。发送前还有一道泄漏检查：若载荷仍包含用户名、家目录、盘符或环境变量值，请求会被拒绝（日志只记类别，不记值）。

请求发往你在设置里填写的 **OpenAI 兼容接口**（`base_url` + `model`）；数据如何保存与使用由该服务商的条款决定，Disk Warden 不向任何第三方转发。未配置接口时不会启用。

## 5. API Key 存在哪里

- 只用 Windows DPAPI（`CryptProtectData`）加密，密文经 Base64 写入 `<数据目录>\config\ai-key.bin`。
- 密文绑定**当前 Windows 用户 + 当前机器**；把文件拷到别的机器或别的账户无法解密。
- Key 不写入 `settings.json`、不写日志、不出现在设置接口返回值里（只暴露 `api_key_set` / `api_key_source`）。
- 安装包内**不含任何 Key**，也没有明文 Key 字符串。
- 删除 `ai-key.bin` 并关闭 AI 开关即可彻底移除密钥；重新输入需再次同意。

## 6. 本机数据与缓存

| 位置 | 内容 |
|---|---|
| `<数据目录>\data\` | 迁移后的数据副本 |
| `<数据目录>\config\settings.json` | 设置（不含 Key） |
| `<数据目录>\config\migration-jobs\` | 迁移/回滚日志（路径、状态、校验值） |
| `<数据目录>\config\history.json` | 操作历史 |
| `<数据目录>\config\ai-key.bin` | DPAPI 加密的 Key（仅启用 AI 后存在） |
| `<数据目录>\logs\` | 运行日志（2 MB × 3 + 按天归档 14 天） |
| `%LOCALAPPDATA%\disk-warden\ai-cache.json` | AI 判定缓存，默认 30 天 |

数据目录默认 `D:\DiskWarden`，不可写时依次回退到 `%LOCALAPPDATA%`、`%APPDATA%`、`%USERPROFILE%`、`%TEMP%`，实际路径以设置页为准。

AI 缓存只保存**脱敏路径**与判定结果，不含文件内容；删除该文件即可清除。

## 7. 日志里有什么

日志用于排障，包含：启动版本与数据根、扫描/迁移/回滚的步骤与状态、错误码、路径（本机日志，不对外发送）。不包含：文件内容、API Key 明文、AI 请求全文。

向支持人员反馈时，请只提供 `logs\` 与相关 `migration-jobs\*.json`；如需最小化，可先删除含个人目录名的日志行。

## 8. 你的控制权

- 随时关闭 AI 开关 → 立即停止所有 AI 网络请求；
- 随时删除 `ai-key.bin` → 密钥不可恢复；
- 卸载：托盘退出 → 关闭自启 → 回滚已迁移目录 → 删除解压目录与数据目录；
- 本版本不做自动更新，不会后台下载或安装任何内容。
