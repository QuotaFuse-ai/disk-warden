## 支持环境

| 项目 | 要求 |
|---|---|
| 操作系统 | **仅 Windows 10 / Windows 11，x64** |
| 运行库 | 不需要 Python；需要 Microsoft Edge WebView2 Runtime（Win11 与已更新的 Win10 通常自带） |
| 磁盘 | 目标盘需有 ≥ 待迁移体积的剩余空间 |
| macOS | **尚未提供**，打包与首次启动引导由后续版本跟进 |

## 安装与首次启动

1. **完整解压** zip 到固定目录。不要只把 `DiskWarden.exe` 拖出来，程序依赖同目录的 `_internal`。
2. 双击 `DiskWarden\DiskWarden.exe`。
3. 出现「Windows 已保护你的电脑」时：
   - 点 **更多信息**
   - 点 **仍要运行**

   这是未签名程序的系统提示，不是病毒告警。**请不要关闭 SmartScreen、Defender 或任何系统安全功能**；「仍要运行」只对这次下载的文件生效。
4. 解压目录里的 `START-HERE.txt` 是同一份首次启动说明，可随包分发。
5. 若提示缺少 WebView2，请安装微软官方 WebView2 Runtime 后重开。

## 本版功能

- **扫描**：识别 Cursor、Trae、Claude Code 等 AI IDE 的数据目录，按「可迁移 / 勿动 / 未知」分类并统计体积。
- **迁移**：先备份、再复制、校验通过后改名，原路径变成 junction（目录联接），IDE 无需改配置。迁移前会检测工具进程，运行中拒绝操作。
- **回滚**：一键把目录还原为普通文件夹；中断的迁移在下次启动时自动识别并提供恢复/回滚。
- **托盘常驻**：关闭窗口缩到托盘，托盘菜单可显示/隐藏、打开日志、退出。
- **开机自启**：设置里开启后写入当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，**不需要管理员权限**；关闭即删除。
- **日志**：`logs/app.log` 按 2 MB × 3 轮转，另有按天 JSONL 保留 14 天；设置页可直接打开日志目录。
- **可选 AI 分析**：默认关闭，仅对「未知」目录生效；启用前需显式同意，密钥用 Windows DPAPI 加密保存在本机。

## 验证范围

- 已在本机真实验证：Cursor、Trae、Claude Code 三种目录布局的扫描与迁移。
- 其他 IDE 由 catalog 与规则覆盖，**尚未逐真机验证**，遇到异常请附日志反馈。
- 打包产物已在沙箱通过：扫描 → 迁移 → 校验 → 回滚，以及复制中/改名后强杀的重启恢复。

## 已知限制

1. **未签名**：SmartScreen 每次新下载都会提示；企业策略可能直接拦截。
2. **仅 Windows x64**：32 位与 ARM64 未提供；macOS 待后续版本。
3. **低完整性环境**：从低完整性进程启动时，创建 junction 可能报 `WinError 5`（修复尚未合入主线）。
4. **迁移前须退出 IDE**：进程守护会拒绝在工具运行时迁移/回滚，这是保护数据的设计。
5. **不做自动更新**：升级请解压到**新目录**，不要覆盖旧目录（旧 `python3XX.dll` 残留会导致启动失败，启动器会提示并退出码 3）。

## 升级与卸载

- 升级：退出托盘 → 解压新版到新目录 → 如需保留设置，先关闭旧版自启，再在新版重新开启。
- 卸载：托盘退出 → 关闭开机自启 → 若迁移过目录先在应用内回滚 → 删除解压目录与数据目录（默认 `D:\DiskWarden`）。

## 反馈

请附 `logs/app.log` 与 `config/migration-jobs/<任务号>.json`。日志与配置中不含明文 API Key。
