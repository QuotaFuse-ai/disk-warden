## 2. Python 版本决策

1. **代码基线兼容 Python 3.8+。** 实现中不使用 3.9+ 才有的语法与标准库：内置泛型注解（`list[str]`）、`match`、字典合并 `|`、`zoneinfo`、`tomllib` 等一律禁止；类型注解使用 `typing` 写法。
2. **本地开发与首次打包先用 3.8.6。** 依赖必须锁定到仍支持 3.8 的版本（pywebview / pythonnet / PyInstaller），并在 `requirements` 中固定版本号；不引入要求 3.9+ 的依赖。
3. **3.12 仍是正式发布基线。** GitHub 等 CI 就绪后，用 3.12 出正式包；在此之前 3.8 构建产物标注"预览版"。切换时只需换解释器与锁定版本，不改业务代码。
4. **风险与回退**：Python 3.8 已于 2024-10 停止安全维护，且新版本打包工具逐步放弃 3.8。若 pywebview/WebView2 在 3.8 上不可用，立即改为安装 3.12（免费），不强行留在 3.8。

## 3. 费用澄清

- **Python 本身免费**，安装 3.12 不产生费用；GitHub Actions 公开仓库的构建也免费。
- 真正需要付费的只有：Windows 代码签名证书、Apple Developer 账号（公证，约 99 美元/年）。这两项按人类指示后续再定，不阻塞开发。

## 4. macOS 首次启动引导

1. **提供使用说明是可行的，且必须做。** 未签名应用首次打开会被 Gatekeeper 拦截，这不是错误，需要引导用户放行。
2. **说明载体**：README/下载页的"首次启动"章节 + 应用内首次启动引导弹窗（P1，随 T21 交付）。
3. **文案按系统版本区分**：
   - macOS 15（Sequoia）及更新：**只能**通过"系统设置 → 隐私与安全性 → 仍要打开"，右键打开已不可用。
   - macOS Ventura ~ Sonoma：右键（或 Control 点击）应用 → 打开 → 再次确认。
   - 终端命令（`xattr -dr com.apple.quarantine`）仅作为"高级用户"折叠项，并注明它会让系统跳过对该应用的来源检查，不建议普通用户使用。
4. **推荐顺序**：优先引导用户走系统设置（官方路径），不在首屏推荐终端命令。
5. 签名与公证仍是消除提示的根本方案；预算确认前，引导说明是合规且必要的过渡手段。
