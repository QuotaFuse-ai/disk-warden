DiskWarden 0.9.0-beta.8（macOS，Apple Silicon / arm64）使用说明
================================================================

一、第一次打开（未签名构建，macOS 会拦截一次）
1. 把整个 zip 解压到一个固定目录（例如“应用程序”或桌面下的文件夹），
   不要只把里面的 DiskWarden.app 拖出来单独运行。
   访达里应用显示名为 Disk Warden，文件名是 DiskWarden.app。
2. 双击 DiskWarden.app。macOS 会提示“无法验证开发者”，这是未做
   代码签名与公证的正常提示，不是病毒告警。

   macOS 15（Sequoia）及更新版本：
   a. 提示框里点“完成”/“好”，关掉它；
   b. 打开 系统设置 → 隐私与安全性；
   c. 向下滚动到“安全性”，能看到刚才被拦截的 Disk Warden，
      点“仍要打开”；
   d. 输入登录密码（或 Touch ID），再在确认框里点“仍要打开”。
   说明：macOS 15 起“右键 → 打开”已不再能绕过首次拦截，
   必须走上面的“系统设置 → 仍要打开”。

   macOS Ventura（13）~ Sonoma（14）：
   a. 在访达里按住 Control 键点按（或右键）DiskWarden.app；
   b. 选“打开”；
   c. 在提示框里再点一次“打开”，之后双击即可正常启动。

3. 主窗口出现后即可使用。托盘、日志、开机自启均已可用。

   注意（0.9.0-beta 的已知限制）：本版 macOS 的自动扫描尚未支持——
   IDE 目录清单目前只有 Windows 版，所以在 Mac 上扫描结果为 0 个
   软件，列表是空的，这是预期行为，不是安装失败。界面、迁移引擎、
   符号链接与回滚都已就绪；自动发现会在后续版本补齐。
4. 托盘图标出现在菜单栏；关闭窗口只是隐藏，从菜单栏图标里“退出”
   才会结束进程。
5. 下次启动不再拦截。应用内“设置 → 首次启动说明”可以随时重看这些步骤。

   高级选项（不推荐）：如果上面两步都无效，可以在终端里移除应用的
   隔离属性：
       xattr -dr com.apple.quarantine "/Applications/Disk Warden.app"
   风险：这条命令去掉的是整个 App 的 Gatekeeper 来源标记，相当于放弃
   系统对下载来源的检查；路径写错会作用到别的程序。只有在你能确认
   zip 来自官方发布页、且上面的正常步骤确实失效时才使用。
   根治办法是代码签名 + 公证，本期（0.9.0-beta）不做。

二、运行环境
- macOS 11（Big Sur）及以上。
- 本包是 Apple Silicon（arm64）构建；Intel Mac 需要另行构建的 x64 包。
- 不需要安装 Python。

三、数据与日志放在哪
- 默认数据目录：~/Library/Application Support/DiskWarden
  （即“资源库/Application Support/DiskWarden”，访达里按
  Command+Shift+G 输入路径可直接定位）。
- 迁移目标目录默认也在该数据目录下；可在设置页修改，实际路径以
  设置页显示为准。
- 日志：<数据目录>/logs/app.log。超过 2 MB 自动轮转为 app.log.1/.2，
  另按天写 JSONL 归档日志，保留 14 天。
- 设置页可以直接打开日志目录。

四、托盘与开机自启
- 关闭窗口不会退出程序，而是留在菜单栏；请从菜单栏图标“退出”。
- 设置 → 开机自启：写入当前用户的
  ~/Library/LaunchAgents/com.quotafuse.diskwarden.plist，
  不需要管理员权限，也不改动系统全局设置；关闭开关会删除该文件。
- 与 Windows 版一样，登录项在下次登录时生效。

五、迁移前请先退出 IDE
- 迁移会把选中的缓存目录搬到数据盘，并在原位置建立一个符号链接
  （symlink，ln -s），对 IDE 透明。
- 虽然 macOS 不像 Windows 那样因为文件被占用而重命名失败，仍建议
  迁移与回滚前完全退出对应 IDE（Cursor / Trae / Claude Code 等），
  避免 IDE 在切换瞬间写入缓存。
- 删除链接本身不会碰到目标目录里的数据；应用内的“回滚”只删除自己
  创建的链接，并先校验链接指向是否仍是迁移目标。
- 详细步骤见发布页的《迁移与回滚指南》。

六、卸载
1. 从菜单栏图标退出程序。
2. 在设置中关闭“开机自启”（删除 LaunchAgent）。
3. 如果迁移过目录，先在应用内执行“回滚”，确认原目录已恢复为普通文件夹。
4. 删除 DiskWarden.app 和 ~/Library/Application Support/DiskWarden。

七、遇到问题
- 打开设置页的“日志目录”，把 logs/app.log 与
  config/migration-jobs/ 下对应任务号的 json 一起反馈。
- 日志里不会出现明文 API Key；即使启用 AI 分析，Key 也只保存在本机
  加密文件中。
